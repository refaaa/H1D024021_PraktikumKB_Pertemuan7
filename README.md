# Praktikum Pertemuan 7

## Deskripsi Program

Program ini digunakan untuk melakukan klasifikasi dataset Iris menggunakan metode Jaringan Syaraf Tiruan (JST) dengan bantuan TensorFlow dan Keras. Model akan mempelajari data bunga Iris berdasarkan fitur seperti sepal dan petal untuk menentukan jenis bunga.

---

## Alur Program

Program berjalan melalui beberapa tahapan utama sebagai berikut:

1. Membaca Dataset : Dataset Iris dimuat dari file CSV kemudian dipisahkan menjadi data fitur dan label.

2. Pengolahan Data : Label diubah menjadi bentuk numerik dan data dibagi menjadi data latih serta data uji.

3. Pembuatan Model : Model Jaringan Syaraf Tiruan dibuat menggunakan beberapa hidden layer dengan fungsi aktivasi tertentu.

4. Proses Training : Model dilatih menggunakan data training untuk mengenali pola pada dataset Iris.

5. Evaluasi dan Visualisasi :
   - Menampilkan nilai accuracy dan loss
   - Menampilkan grafik hasil training
   - Menampilkan confusion matrix

6. Prediksi Data : Model digunakan untuk memprediksi jenis bunga Iris berdasarkan input data baru.

--
## Hasil Pelatihan
Hasil pelatihan menampilkan:
- Nilai accuracy
- Nilai loss
- Grafik training dan validation
- Confusion matrix
- Prediksi kelas bunga Iris

Model JST berhasil melakukan klasifikasi dataset Iris dengan tingkat akurasi yang baik.
